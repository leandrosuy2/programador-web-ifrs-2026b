# Programador Web — IFRS 2026B

Portfólio de estudos de Leandro Dantas, organizado pelos seis módulos do curso de 200 horas.

Este repositório reúne os projetos práticos do curso de 200 horas. As implementações iniciais e os resultados de verificações estão organizados por módulo; itens que exigem execução em ferramenta específica, reflexão pessoal ou revisão do estudante permanecem identificados como pendentes. A marcação de leitura no Moodle não comprova a implementação destes projetos.

## Projeto final: DevTrack

Aplicação para cadastrar projetos e tarefas, acompanhar prazos e visualizar progresso. O MVP usa HTML, CSS e JavaScript puro, com persistência local no navegador, filtros e backup JSON. Testes automatizados cobrem validação e métricas; os fluxos principais também foram verificados no navegador. A modelagem relacional e a especificação UML acompanham o código. A integração com um servidor é uma evolução opcional, porque este curso não possui módulo de backend.
