# Decisões iniciais

- Monorepositório: facilita demonstrar a evolução dos seis módulos e a integração final.
- JavaScript puro: permite mostrar os fundamentos sem esconder a lógica em um framework.
- Portugol no módulo de lógica: corresponde ao ambiente citado no índice do curso.
- IndexedDB no MVP: entrega persistência executável sem acrescentar backend não coberto pelo curso.
- SQL e DER: evidência separada de modelagem relacional; SQL é prática extra proposta.
- Progresso registrado por entrega e evidência, com datas reais de commits.
- Aplicação final é uma extensão de portfólio, não uma exigência oficial identificada no Moodle.
