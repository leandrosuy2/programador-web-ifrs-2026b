## Fluxo Git

Use `main` para a versão revisada. Trabalhe em branches como `modulo/01-html` e `feature/devtrack-tarefas`. Revise o diff antes de cada commit. Mensagens: `feat` para recurso, `fix` para correção, `docs` para documentação, `test` para verificações e `refactor` para reorganização sem alterar comportamento. Não crie commits vazios apenas para preencher o calendário.
