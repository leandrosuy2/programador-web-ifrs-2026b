## Rubrica de autoavaliação por entrega

Pontue cada dimensão de 0 a 4: 0 ausente; 1 incompleta; 2 básica com problemas; 3 atende aos critérios; 4 atende e demonstra revisão consistente.

| Dimensão | O que observar |
|---|---|
| Funcionamento | Os cenários de aceitação passam? |
| Organização | Código e arquivos são legíveis e coerentes? |
| Acessibilidade/validação | Navegação, entradas e mensagens são adequadas à entrega? |
| Verificação | Há casos normais, limites e evidência das correções? |
| Comunicação | README explica execução, decisões e limitações? |

Total máximo: 20 pontos por entrega. Esta autoavaliação é do portfólio e não substitui a nota oficial do IFRS.
