# Módulo 2: CSS

**Projeto proposto:** Site responsivo de apresentação de serviços  
**Status:** primeira versão implementada; validação em navegador pendente
**Materiais de referência:** 2.1–2.11

## Enunciado

Seletores por tag, classe e ID; tipografia; estados de links; menu com listas; box model; posicionamento; media queries; layout adaptado a celular e desktop.

## Execução

Abra `src/index.html` no navegador. O CSS está em `src/css/styles.css`; as fontes e a fotografia dependem de serviços públicos externos.

## Decisões

O layout usa grid, flexbox, box model global e dois breakpoints. A paleta combina verde profundo, terracota e fundos claros. Links de navegação têm estado hover e foco visível.
